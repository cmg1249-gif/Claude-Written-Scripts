DEADLINK v2 — TEACHER NOTES

Browser game · binary, IP, DHCP, DNS, ports, subnets, OSI · + a Field Terminal with 7 troubleshooting cases · runs in Firefox on Kali, no install, sound optional

The story: a zombie outbreak took the cities and the network went dark one node at a time. Students work from a bunker with a salvaged switch to bring each settlement's node back online, fix what's broken, keep the hordes away, and restore the grid.

The loop (no automation, everything is earned by hand): answer networking problems at a node → 8 right secures it (★) → close that node's Field Terminal case with real Linux commands → spend salvage to bring the next node online. Nothing earns salvage while the tab is closed. Later nodes cost salvage from earlier ones, so students keep going back to practice old skills (binary especially).

The Field Terminal (required to move on)

A simulated Linux terminal with one troubleshooting case per node. Each case is inspect → fix → verify → submit. Commands are real (ls, cd, cat, ip a, ip route, ping, nslookup, nc -zv, curl, dhclient, traceroute). A few [game action] commands stand in for physical repairs and are shown dashed in the command list so students can tell them apart. Hints are free.

Hordes, hints, crews and calm mode

  • Horde watch: wrong answers make noise. 4 noise (6 for the Medics crew) draws a horde: salvage at that node is halved and the next node stays locked until 3 right answers push them back. Time-outs and hints never make noise, so slow readers aren't punished.
  • Hints (H key): every node has one. A hinted answer still pays but doesn't build the streak. On Binary, Reveal place values and Walk me through it (after 2 misses) count as hints too.
  • Crews (picked once at the start): Medics = more room for mistakes, Scavengers = +25% salvage, Ghosts = shake noise faster.
  • Calm mode (Settings → Learning): turns every timer off. Good for a student who freezes under time pressure, or for a node they're seeing for the first time.

Learning report

The Report button shows each node's right / missed / accuracy / hinted / best streak, cases closed, hordes, rank and badges. Students type their name and press Download CSV (works in the downloaded file) or Copy CSV (works everywhere) and send it to you. "Missed" includes time-outs; "Hinted" means they leaned on help, which tells you who needs a check-in.

Teacher tools

Add ?teacher=1 to the end of the address (or #teacher, then reload), then open Settings. Buttons: +1,000 of everything, unlock every node, secure every open node, close every open Field Terminal case, clear every horde, install every upgrade on a node, +30 correct. Use them to demo a later node on the projector or catch up an absent student.

Saves and cleanup

  • Progress saves automatically in that browser. To move it: Settings → Save code → Copy, then Load code on the other machine. Old v1 save codes still load; they get XP credit for past answers and pick a crew.
  • End of class: Settings → Wipe my save from this computer leaves nothing stored. Students copy their save code first if they want to continue next time.
Make it competitive: the certificate shows time to restore the grid, accuracy and hints used. Put a board on the whiteboard (name, time, accuracy, fewest hints).
No sound in the lab? Fine — every reward and mistake also flashes on screen. Sound is a bonus.
Pacing (estimate, not yet timed with students): about 60–100 minutes for a full run, so plan on two sessions. Node 1 plus case 1 is a solid 15–20 minute binary warm-up for a co-taught session; the Field Terminal cases are where most of the time goes.
